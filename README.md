# Hop Albania: udhëzues i faqeve

[Hop](https://hop.al) është tregu online i Shqipërisë: prona me qira dhe në shitje, makina, telefona, laptopë, punë, shërbime dhe më shumë. Ky repo mban një listë të rregullt të faqeve kryesore të Hop, të ndara sipas kategorisë dhe qytetit, që t'i gjesh shpejt.

*Hop is Albania's online marketplace for property, cars, phones, jobs and services. This repository is a plain index of its main pages, by category and city.*

Faqja e repos: https://hopalbania.github.io
